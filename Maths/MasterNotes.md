# Grade 7 Mathematics Master Notes

## Unit 1: Number Sense and Rational Numbers

This unit develops number sense with **integers**, **fractions with unlike denominators**, and **mixed numbers**. The most important idea is that signs and forms may change, but the value of a number does not.

---

### Topic 1: Integers

#### What Are Integers?

**Integers** are whole numbers, their opposites, and zero.

`..., -4, -3, -2, -1, 0, 1, 2, 3, 4, ...`

- Positive integers are greater than zero: `1, 2, 3, ...`
- Negative integers are less than zero: `-1, -2, -3, ...`
- Zero is neither positive nor negative.
- Integers do not include fractions or decimals such as `1/2`, `-2.7`, or `3.14`.
- Two numbers the same distance from zero but on opposite sides, such as `5` and `-5`, are **opposites**.

#### The Number Line

- Values increase as you move **right**.
- Values decrease as you move **left**.
- A number farther right is always greater.
- Negative numbers can be confusing: `-2 > -8` because `-2` is farther right and closer to zero.

#### Problem Type 1: Write an Integer for a Situation

Choose zero as the reference point. Words such as **gain, rise, deposit, above, profit,** and **after** usually suggest a positive integer. Words such as **loss, fall, withdrawal, below, debt,** and **before** usually suggest a negative integer.

**Worked example:** Write an integer for “a withdrawal of $32.”

- A withdrawal reduces the account balance.
- Integer: `-32`

More examples:

| Situation | Integer | Reason |
|---|---:|---|
| A $12 refund | `+12` | Money is returned. |
| 340 feet below sea level | `-340` | Below the reference level is negative. |
| A 19-yard gain | `+19` | A gain is positive. |
| Born 2 days late | `+2` | The birth is after the due date. |
| Two strokes below par | `-2` | Below par is represented by a negative score. |

> **Challenge:** A submarine is 85 feet below sea level, so its position is `-85`. It rises 30 feet, so its new position is `-85 + 30 = -55` feet. A positive change does not guarantee a positive final position.

#### Problem Type 2: Find Absolute Value

The **absolute value** of a number is its distance from zero. Distance is never negative.

- `|7| = 7`
- `|-7| = 7`
- `|0| = 0`

**Worked example:** Evaluate `|-102|`.

`-102` is 102 units from zero, so `|-102| = 102`.

**Common trap:** The bars do not automatically mean “make the number positive” in every expression. First evaluate what is inside.

Example: `|3 - 11| = |-8| = 8`.

> **Challenge:** Evaluate `-|-9| + |4 - 10|`.
>
> `-|-9| + |4 - 10| = -9 + |-6| = -9 + 6 = -3`
>
> The negative sign outside `|-9|` remains after the absolute value is evaluated.

#### Problem Type 3: Compare Integers

Use `<` for “less than” and `>` for “greater than.” Compare evaluated values, not just the symbols you first see.

**Worked examples:**

- `-8 < 3` because `-8` lies left of `3`.
- `25 > -23` because every positive number is greater than every negative number.
- `|13| > -25` because `13 > -25`.
- `|-9| > |-4|` because `9 > 4`.

> **Challenge:** Compare `-|12|` and `|-15| - 4`.
>
> Left side: `-|12| = -12`  
> Right side: `|-15| - 4 = 15 - 4 = 11`  
> Therefore, `-|12| < |-15| - 4`.

#### Problem Type 4: Order Integers

To order integers from least to greatest, imagine their positions from left to right on a number line.

**Worked example:** Order `{-8, 3, -2, 0, 5, -11}` from least to greatest.

`-11, -8, -2, 0, 3, 5`

Among negative numbers, the number with the larger absolute value is smaller: `-11 < -8`.

> **Challenge:** Order `{|-6|, -|8|, 3 - 10, 0, -(-4)}`.
>
> First evaluate: `{6, -8, -7, 0, 4}`.  
> Least to greatest: `-8, -7, 0, 4, 6`.

#### Problem Type 5: Add Integers

On a number line, addition means move:

- right for a positive addend;
- left for a negative addend.

Rules:

1. **Same signs:** Add the absolute values and keep the common sign.
   - `-12 + (-7) = -19`
2. **Different signs:** Subtract the smaller absolute value from the larger absolute value. Keep the sign of the number with the larger absolute value.
   - `-15 + 22 = 7`
3. **Opposites:** Their sum is zero.
   - `-9 + 9 = 0`

**Worked example:** Find `-22 + 12`.

- The signs differ.
- `22 - 12 = 10`.
- `-22` has the larger absolute value, so the answer is negative.
- `-22 + 12 = -10`

> **Challenge:** Evaluate `-38 + 17 + (-12) + 43`.
>
> Regroup conveniently: `(-38 + 43) + (17 - 12) = 5 + 5 = 10`.

#### Problem Type 6: Subtract Integers

Subtracting a number is equivalent to adding its opposite:

`a - b = a + (-b)`

A useful memory aid is **Keep, Change, Change**:

1. Keep the first number.
2. Change subtraction to addition.
3. Change the second number to its opposite.

**Worked examples:**

- `6 - 14 = 6 + (-14) = -8`
- `-7 - 5 = -7 + (-5) = -12`
- `-9 - (-4) = -9 + 4 = -5`

**Common trap:** In `-9 - (-4)`, the two adjacent negative signs do not make the entire answer positive. They change the operation to `-9 + 4`, whose answer is `-5`.

> **Challenge:** Evaluate `-4 - [7 - (-3)] + |-6|`.
>
> Inside brackets: `7 - (-3) = 10`  
> Absolute value: `|-6| = 6`  
> Then `-4 - 10 + 6 = -8`.

#### Problem Type 7: Integer Applications

1. Choose a reference point such as sea level, zero dollars, par, or the ground floor.
2. Translate each change into a signed number.
3. Write and evaluate an expression.
4. State the answer with units and meaning.

**Worked example - water level:** A lake’s water level is `-14` feet. Rain raises it 23 feet.

`-14 + 23 = 9`

The new water level is **9 feet above** the reference level.

**Worked example - elevator:** An elevator starts on floor 14, rises 5 floors, and descends 8 floors.

`14 + 5 - 8 = 11`

It stops on the **11th floor**.

> **Challenge - bank balance:** An account is overdrawn by $85, receives a $125 deposit, and then pays a $63 bill.
>
> `-85 + 125 - 63 = 40 - 63 = -23`  
> The final balance is `-$23`; the account is still overdrawn by $23.

> **Challenge - distance between levels:** Find the vertical distance between an elevation of `-18` feet and an elevation of `7` feet.
>
> Distance is the absolute value of the difference: `|7 - (-18)| = |25| = 25` feet.


#### Problem Type 8: Divide Integers

Division asks how many equal groups can be made, and it is the inverse of multiplication.

**Sign rules:**

- Same signs give a positive quotient: `24 ÷ 6 = 4` and `-24 ÷ (-6) = 4`.
- Different signs give a negative quotient: `-24 ÷ 6 = -4` and `24 ÷ (-6) = -4`.
- Zero divided by any nonzero integer is zero.
- Division by zero is undefined.

A quick memory rule is: **same signs → positive; different signs → negative**.

**Worked example:** Find `80 ÷ (-10)`.

The signs differ, so the quotient is negative. Since `80 ÷ 10 = 8`, `80 ÷ (-10) = -8`.

**Worked example - average change:** A population falls from 1,000,000 to 100,000 over 10 years.

`(100,000 - 1,000,000) ÷ 10 = -900,000 ÷ 10 = -90,000`

The average change is **-90,000 animals per year**.

**Common traps:**

- Division is not commutative: `12 ÷ 3 = 4`, but `3 ÷ 12 = 1/4`.
- Determine the sign before calculating the absolute-value quotient.
- For a rate of change, calculate `(new value - original value) ÷ elapsed time` and interpret the sign.

> **Challenge:** The temperature changes from `63°F` to `-21°F` in 12 hours. The average hourly change is `(-21 - 63) ÷ 12 = -84 ÷ 12 = -7°F` per hour.

### Topic 2: Add and Subtract Unlike Fractions

#### Like and Unlike Fractions

- **Like fractions** have the same denominator, such as `3/8` and `5/8`.
- **Unlike fractions** have different denominators, such as `3/8` and `5/12`.
- A denominator names the size of the pieces. Fractions can be added or subtracted only after the pieces have the same size.
- The **least common denominator (LCD)** is the least common multiple of the denominators.

General process:

1. Find the LCD.
2. Rename each fraction as an equivalent fraction with the LCD.
3. Add or subtract the numerators.
4. Keep the common denominator.
5. Simplify.

#### Problem Type 1: Find the LCD

**Worked example:** Find the LCD of `12` and `18` using prime factorization.

- `12 = 2^2 x 3`
- `18 = 2 x 3^2`
- Use the greatest power of each prime: `2^2 x 3^2 = 36`

Therefore, the LCD is `36`.

**Common trap:** Multiplying the denominators always produces a common denominator, but it may not be the *least* common denominator.

> **Challenge:** Find the LCD of `18`, `24`, and `30`.
>
> `18 = 2 x 3^2`, `24 = 2^3 x 3`, and `30 = 2 x 3 x 5`.  
> LCD `= 2^3 x 3^2 x 5 = 360`.

#### Problem Type 2: Add Positive Unlike Fractions

**Worked example:** Find `3/8 + 5/12`.

- LCD of 8 and 12 is 24.
- `3/8 = 9/24`
- `5/12 = 10/24`
- `9/24 + 10/24 = 19/24`

Therefore, `3/8 + 5/12 = 19/24`.

**Visual meaning:** On a number line or fraction model, both fractions must be divided into equal-sized twenty-fourths before their lengths can be combined.

#### Problem Type 3: Add Fractions with Negative Values

**Worked example:** Find `-3/4 + 5/6`.

- LCD is 12.
- `-3/4 = -9/12` and `5/6 = 10/12`.
- `-9/12 + 10/12 = 1/12`.

The positive fraction has the larger absolute value, so the answer is positive.

#### Problem Type 4: Subtract Unlike Fractions

**Worked example:** Find `7/10 - 1/6`.

- LCD is 30.
- `7/10 = 21/30` and `1/6 = 5/30`.
- `21/30 - 5/30 = 16/30 = 8/15`.

Therefore, `7/10 - 1/6 = 8/15`.

#### Problem Type 5: Subtract a Negative Fraction

Subtracting a negative fraction becomes addition:

**Worked example:**

`2/5 - (-3/8) = 2/5 + 3/8 = 16/40 + 15/40 = 31/40`

**Common trap:** Apply the sign rule before finding the LCD. The denominator is not affected by the subtraction sign.

#### Problem Type 6: Grouped and Multi-Step Fraction Expressions

Use the order of operations. Simplify strategically, but do not add or subtract across unlike denominators.

**Worked example:** Find `(-3/5 + 7/10) + 1/4`.

- Inside parentheses: `-3/5 + 7/10 = -6/10 + 7/10 = 1/10`.
- Then `1/10 + 1/4 = 2/20 + 5/20 = 7/20`.

The Commutative and Associative Properties can sometimes be used to reorder and regroup addends. They do **not** allow terms to be reordered across subtraction without first rewriting subtraction as addition of the opposite.

> **Challenge:** Evaluate `5/12 - (-7/18) + 1/8`.
>
> LCD of 12, 18, and 8 is 72.  
> `5/12 = 30/72`, `7/18 = 28/72`, and `1/8 = 9/72`.  
> `30/72 + 28/72 + 9/72 = 67/72`.

> **Challenge:** Evaluate `1 - [3/8 + (5/12 - 1/6)]`.
>
> `5/12 - 1/6 = 5/12 - 2/12 = 1/4`  
> `3/8 + 1/4 = 3/8 + 2/8 = 5/8`  
> `1 - 5/8 = 3/8`.

#### Problem Type 7: Estimate and Check Reasonableness

Use benchmark fractions such as `0`, `1/2`, and `1`.

**Worked example:** Estimate `7/8 - 1/3`.

- `7/8` is close to `1`.
- `1/3` is reasonably close to `1/2` for a quick estimate.
- Estimated difference: about `1/2`.
- Exact result: `21/24 - 8/24 = 13/24`, which is close to `1/2`.

Also check subtraction by addition: if `a - b = c`, then `c + b` should equal `a`.

#### Problem Type 8: Fraction Applications

**Worked example - combine distances:** A cyclist rides `2/3` mile and then `5/8` mile.

`2/3 + 5/8 = 16/24 + 15/24 = 31/24 = 1 7/24`

The cyclist rides `1 7/24` miles in all.

**Worked example - remaining amount:** A student saves `1/5` of an allowance and spends `2/3` of it. What remains?

`1 - 1/5 - 2/3 = 15/15 - 3/15 - 10/15 = 2/15`

`2/15` of the allowance remains.

#### Problem Type 9: Find a Missing Fraction

When all categories form one whole, their fractions add to `1`.

**Worked example:** A student spends `1/2` of homework time on math and `1/3` on English. The rest is science.

`1 - 1/2 - 1/3 = 6/6 - 3/6 - 2/6 = 1/6`

The student spends `1/6` of the time on science.

> **Challenge:** Solve `x + 7/15 = 11/12`.
>
> `x = 11/12 - 7/15 = 55/60 - 28/60 = 27/60 = 9/20`.

#### Problem Type 10: Unit Fractions and Mental Addition

A **unit fraction** has numerator 1, such as `1/2` or `1/9`.

For nonzero denominators `a` and `b`:

`1/a + 1/b = (a + b)/(ab)`

This formula always produces a common denominator, although the result may need simplification.

**Worked example:**

`1/6 + 1/15 = (15 + 6)/(6 x 15) = 21/90 = 7/30`

#### Problem Type 11: Counterexamples

A **counterexample** is one example that proves a universal statement false.

**Claim:** “The sum of three fractions with odd numerators is never `1/2`.”

**Counterexample:**

`1/6 + 1/6 + 1/6 = 3/6 = 1/2`

All three numerators are odd, so this one example disproves the claim.

#### Common Errors with Unlike Fractions

- Incorrect: `2/3 + 3/5 = 5/8`
- Correct: `2/3 + 3/5 = 10/15 + 9/15 = 19/15 = 1 4/15`
- Do not add or subtract denominators.
- Multiply both numerator and denominator by the same factor when renaming a fraction.
- Simplify only when numerator and denominator share a common factor.
- Keep negative signs attached to the value they belong to.

### Topic 3: Add and Subtract Mixed Numbers

#### Understanding Mixed Numbers

A **mixed number** contains a whole number and a proper fraction, such as `4 2/3`.

An **improper fraction** has a numerator greater than or equal to its denominator, such as `14/3`.

Conversions:

- Mixed to improper: multiply the whole number by the denominator, add the numerator, and keep the denominator.
- Improper to mixed: divide the numerator by the denominator; the quotient is the whole number and the remainder becomes the numerator.

Examples:

- `4 2/3 = (4 x 3 + 2)/3 = 14/3`
- `17/5 = 3 2/5`

#### Problem Type 1: Add Mixed Numbers

**Worked example:** Find `7 3/4 + 10 2/3`.

- LCD of 4 and 3 is 12.
- `3/4 = 9/12` and `2/3 = 8/12`.
- Fraction sum: `9/12 + 8/12 = 17/12 = 1 5/12`.
- Whole-number sum: `7 + 10 = 17`.
- Combine the extra whole: `17 + 1 5/12 = 18 5/12`.

Therefore, `7 3/4 + 10 2/3 = 18 5/12`.

#### Problem Type 2: Subtract without Regrouping

**Worked example:** Find `8 5/6 - 2 1/3`.

- Rename `1/3` as `2/6`.
- Subtract fractions: `5/6 - 2/6 = 3/6 = 1/2`.
- Subtract whole numbers: `8 - 2 = 6`.

Therefore, `8 5/6 - 2 1/3 = 6 1/2`.

#### Problem Type 3: Subtract by Regrouping One Whole

Regroup when the fraction in the first mixed number is smaller than the fraction being subtracted.

Remember that one whole can be written as `d/d`, where `d` is the denominator.

**Worked example:** Find `6 1/4 - 2 5/6`.

- LCD is 12: `6 1/4 = 6 3/12` and `2 5/6 = 2 10/12`.
- Since `3/12 < 10/12`, borrow one whole from 6.
- `6 3/12 = 5 (12/12 + 3/12) = 5 15/12`.
- Subtract: `5 15/12 - 2 10/12 = 3 5/12`.

Therefore, `6 1/4 - 2 5/6 = 3 5/12`.

**Common trap:** When borrowing, decrease the whole-number part by 1 and add a complete fraction such as `12/12`, not just `1/12`.

#### Problem Type 4: Use Improper Fractions to Subtract

This is an alternative to regrouping.

**Worked example:** Find `2 1/3 - 1 3/4`.

- `2 1/3 = 7/3`
- `1 3/4 = 7/4`
- `7/3 - 7/4 = 28/12 - 21/12 = 7/12`

Both the regrouping method and the improper-fraction method must produce the same answer.

#### Problem Type 5: Add When the Fraction Sum Exceeds One

**Worked example:** Find `4 7/8 + 3 5/6`.

- LCD is 24.
- `7/8 = 21/24` and `5/6 = 20/24`.
- `21/24 + 20/24 = 41/24 = 1 17/24`.
- `4 + 3 + 1 17/24 = 8 17/24`.

#### Problem Type 6: Signed Mixed Numbers

Treat the negative sign as applying to the entire mixed number.

**Worked examples:**

- `-3 1/4 + (-1 2/3) = -(3 1/4 + 1 2/3) = -5 1/12`
- `-6 3/5 + 2 7/10 = -33/5 + 27/10 = -66/10 + 27/10 = -39/10 = -3 9/10`
- `-2 3/5 - (-5 7/10) = -2 3/5 + 5 7/10 = 3 1/10`

**Notation warning:** `-3 1/4` means `-(3 1/4)`, not `(-3) + 1/4`.

#### Problem Type 7: Multi-Term Mixed-Number Expressions

**Worked example:** Evaluate `6 1/3 + 1 1/2 - 2 5/9`.

- Whole-number calculation: `6 + 1 - 2 = 5`.
- LCD of 3, 2, and 9 is 18.
- Fraction calculation: `6/18 + 9/18 - 10/18 = 5/18`.
- Answer: `5 5/18`.

> **Challenge:** Evaluate `12 1/6 - [3 3/4 + 2 5/9]`.
>
> Inside brackets, LCD is 36:  
> `3 3/4 + 2 5/9 = 3 27/36 + 2 20/36 = 5 47/36 = 6 11/36`.  
> `12 1/6 = 12 6/36 = 11 42/36`.  
> `11 42/36 - 6 11/36 = 5 31/36`.

#### Problem Type 8: Mixed-Number Applications

**Worked example - fill a tank:** A gas tank holds `11 9/10` gallons and contains `8 3/4` gallons. How much more is needed?

`11 9/10 - 8 3/4 = 11 18/20 - 8 15/20 = 3 3/20`

The tank needs `3 3/20` more gallons.

**Worked example - elapsed time:** Morning preparation takes `1 1/4` hours and breakfast takes `3/4` hour.

`1 1/4 + 3/4 = 1 + 4/4 = 2` hours.

If preparation begins at 6:00 a.m., it ends at 8:00 a.m.

#### Problem Type 9: Work Backward

Some problems describe operations performed on an unknown starting value. Represent the starting value with a variable and undo the operations.

> **Challenge - original string length:** A string is cut in half. One half is discarded. Then `1/5` of the remaining half is cut away, leaving 8 feet. Find the original length.
>
> Let the original length be `L`. After half is discarded, `L/2` remains. Cutting away `1/5` leaves `4/5` of that half:  
> `(4/5)(L/2) = 8`  
> `2L/5 = 8`  
> `2L = 40`  
> `L = 20`  
> The original string was **20 feet** long.

> **Challenge - missing mixed number:** Solve `x - 2 7/12 = 4 5/18`.
>
> Add `2 7/12` to both sides:  
> `x = 4 5/18 + 2 7/12`  
> LCD is 36: `5/18 = 10/36` and `7/12 = 21/36`.  
> `x = 6 31/36`.

#### Estimation and Reasonableness with Mixed Numbers

Round each mixed number to a nearby whole number or benchmark fraction before calculating.

Example: `8 5/6 - 2 1/3` is approximately `9 - 2 = 7`. The exact answer `6 1/2` is close to 7, so it is reasonable.

#### Common Errors with Mixed Numbers

- Adding or subtracting denominators.
- Forgetting to simplify the final fraction.
- Failing to rename unlike fractional parts with the LCD.
- Borrowing `1/d` instead of a complete whole `d/d`.
- Forgetting to carry an improper fraction’s extra whole into the whole-number part.
- Treating the negative sign of a negative mixed number as if it applies only to the whole-number part.
- Giving a number without units or context in a word problem.

### Topic 4: Multiply and Divide Fractions

#### Multiply Fractions and Mixed Numbers

1. Rewrite mixed numbers as improper fractions.
2. Cancel common factors across numerators and denominators when possible.
3. Multiply the numerators.
4. Multiply the denominators.
5. Simplify and convert to a mixed number when appropriate.

**Worked example:** `2 1/4 × 1 2/3`

`2 1/4 = 9/4` and `1 2/3 = 5/3`.

`9/4 × 5/3 = 45/12 = 15/4 = 3 3/4`.

Canceling before multiplying can make the arithmetic easier: the 9 and 3 share a factor of 3.

**Applications:** Multiplication is useful for finding a fraction of a quantity, scaling a recipe, and finding area.

Example: `3/5` of 180 minutes is `3/5 × 180 = 108` minutes.

#### Divide Fractions and Mixed Numbers

Use **Keep, Change, Flip**:

1. Keep the first fraction.
2. Change division to multiplication.
3. Flip the second fraction to its reciprocal.
4. Multiply and simplify.

**Worked example:** `3 1/2 ÷ 7/8`

`7/2 ÷ 7/8 = 7/2 × 8/7 = 4`.

Division asks how many groups of the divisor fit into the dividend.

**Common traps:**

- Flip only the divisor, not the first fraction.
- Convert mixed numbers before multiplying or dividing.
- A quotient can be greater than the dividend when dividing by a positive fraction less than 1.
- Zero has no reciprocal, so division by zero is undefined.

> **Challenge:** A `8 1/4`-foot ladder has 6 equal spaces. Each space is `8 1/4 ÷ 6 = 33/4 × 1/6 = 11/8 = 1 3/8` feet.

### Topic 5: Terminating and Repeating Decimals

#### Fractions as Decimals

A fraction represents division: `a/b = a ÷ b`.

- A **terminating decimal** ends, such as `4/5 = 0.8`.
- A **repeating decimal** has a digit or block that repeats forever, such as `4/9 = 0.444... = 0.\overline{4}`.
- Preserve the negative sign when converting negative fractions or mixed numbers.

After a fraction is simplified, its decimal terminates exactly when the denominator has no prime factors other than 2 and 5.

Examples:

- `7/20 = 0.35` terminates because `20 = 2^2 × 5`.
- `5/12 = 0.41666... = 0.41\overline{6}` repeats because the simplified denominator includes a factor of 3.

#### Decimals as Fractions

Use place value, then simplify.

- `-0.9 = -9/10`
- `0.34 = 34/100 = 17/50`
- `2.66 = 266/100 = 133/50 = 2 33/50`

A whole number can be written with denominator 1, and a negative decimal becomes a negative fraction.

**Time warning:** Minutes are parts of 60, not parts of 100. Therefore, 2 hours 18 minutes is `2 + 18/60 = 2.3` hours, not `2.18` hours.

> **Challenge:** Convert `0.\overline{27}` to a fraction. Let `x = 0.272727...`. Then `100x = 27.272727...`. Subtract: `99x = 27`, so `x = 27/99 = 3/11`.


#### Rational and Irrational Numbers

A **rational number** is any number that can be written as a fraction `p/q`, where `p` and `q` are integers and `q ≠ 0`.

Rational numbers include:

- integers, because `7 = 7/1`;
- fractions and mixed numbers;
- terminating decimals, such as `0.35 = 7/20`;
- repeating decimals, such as `0.\overline{4} = 4/9`.

An **irrational number** cannot be written as a fraction of two integers. Its decimal representation:

1. never terminates, **and**
2. never settles into a repeating digit or repeating block.

Examples include `π = 3.14159265...`, `√2 = 1.41421356...`, and `√3 = 1.73205080...`.

| Number form | Rational or irrational? | How to identify it |
|---|---|---|
| Integer or fraction | Rational | It is already a ratio of integers or can be written over 1. |
| Terminating decimal | Rational | Write it over a power of 10 and simplify. |
| Repeating decimal | Rational | Algebra can convert its repeating pattern into a fraction. |
| Nonterminating, nonrepeating decimal | Irrational | It continues forever without any repeating pattern. |
| Square root of a perfect square | Rational | Example: `√49 = 7`. |
| Square root of a non-perfect-square integer | Irrational | Example: `√5` is irrational. |

**Important clarifications:**

- A decimal is not irrational merely because it has many digits. It must continue forever **without repeating**.
- Repeating decimals are always rational—even when some digits occur before the repeating part.
- Not every square root is irrational. Always check whether the number inside the radical is a perfect square.
- If only a shortened decimal is shown, you may need more information or a bar/pattern rule to determine whether it terminates or repeats.

> **Special Concept — Converting a Repeating Decimal to a Fraction**
>
> The notation `5.8\overline{5}` means `5.85555...`; only the final digit `5` repeats. This number is rational because it can be converted exactly into a fraction.
>
> Let `x = 5.85555...`.
>
> First multiply by 10 to move past the one nonrepeating decimal digit:
>
> `10x = 58.55555...`
>
> Then multiply the original number by 100 to move one additional place—the length of the repeating block:
>
> `100x = 585.55555...`
>
> Subtract the equations:
>
> `100x - 10x = 585.55555... - 58.55555...`
>
> The identical repeating tails cancel:
>
> `90x = 527`
>
> Divide both sides by 90:
>
> `x = 527/90`
>
> Therefore, `5.8\overline{5} = 527/90`, proving that it is **rational**.
>
> **Why the trick works:** Multiplication shifts the decimal point until the repeating parts line up. Subtraction removes the infinite repeating tails and leaves an ordinary equation.

**Bar-notation warning:** The bar belongs only above the digit or block that repeats.

- `5.8\overline{5} = 5.85555...`
- `5.\overline{85} = 5.858585...`

These are different numbers, so bar placement matters.

### Topic 6: Square Roots and Irrational Numbers

#### Square Roots and Perfect Squares

The principal square root `√n` is the nonnegative number whose square is `n`.

- `√49 = 7` because `7^2 = 49`.
- If `n` is not a perfect square, `√n` is usually irrational: its decimal neither terminates nor repeats.
- To bracket a square root, locate the neighboring perfect squares.

Example: `49 < 63 < 64`, so `7 < √63 < 8`.

#### Teacher Method: Estimate Between Perfect Squares

The worksheets estimate a non-perfect square between consecutive perfect squares. If `a^2 < n < (a + 1)^2`, they use

`√n ≈ a + (n - a^2)/((a + 1)^2 - a^2)`.

For `√27`:

- `25 < 27 < 36`, so `5 < √27 < 6`.
- Fractional position: `(27 - 25)/(36 - 25) = 2/11`.
- Estimate: `5 2/11 ≈ 5.2`.

> **Accuracy Note:** This is a linear classroom estimate, not an exact square-root calculation. It is often useful to the nearest tenth, but it can differ from the correctly rounded value. For example, the worksheet method gives `√2 ≈ 1.3`, while `√2 = 1.414...` rounds to `1.4`; it gives `√20 ≈ 4.4`, while `√20 = 4.472...` rounds to `4.5`. Follow the method requested by the teacher, and use squaring or a calculator when exact rounding is required.

#### Check an Approximation

If `√n ≈ x`, square the estimate. A good estimate should make `x^2` close to `n`.

Example: `√63 ≈ 7.9`; `7.9^2 = 62.41`, which is close to 63.

#### Square-Root Applications

For a square with area `A`:

- side length: `s = √A`
- perimeter: `P = 4√A`

**Worked example:** A square garden has area 137 square feet.

`s = √137 ≈ 11.7` feet.

**Worked example:** A square frame has outer area `121 in^2` and is 2 inches thick on every side.

- Outer side: `√121 = 11` inches.
- Inner side: `11 - 2 - 2 = 7` inches.
- Picture area: `7^2 = 49 in^2`.

**Common traps:**

- Area is in square units; side length and perimeter are in linear units.
- For a border of thickness `t`, subtract `2t` from the outer side.
- Do not confuse `√(a + b)` with `√a + √b`; they are generally not equal.
