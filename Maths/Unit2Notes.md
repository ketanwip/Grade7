# Grade 7 Mathematics Unit 2 Notes

## Unit 2: Algebraic and Linear Expressions

This unit develops the language and structure of algebra. The central idea is that an expression can change form without changing value. The **Distributive Property**, combining **like terms**, adding and subtracting **linear expressions**, and **factoring** are connected operations.

---

### Topic 1: The Distributive Property

#### Meaning and Symbols

The **Distributive Property** says that to multiply a sum or difference by a number, multiply every term inside the parentheses by the factor outside.

- `a(b + c) = ab + ac`
- `a(b - c) = ab - ac`

The expressions on the two sides are **equivalent expressions**: they have the same value for every allowed value of the variable.

**Algebra-tile meaning:** In `2(x + 2)`, there are two equal groups, each containing one `x`-tile and two unit tiles. Combining both groups gives two `x`-tiles and four unit tiles, so `2(x + 2) = 2x + 4`.

#### Distribute to Evaluate Numerical Expressions

**Worked example:** Evaluate `8(-9 + 4)`.

`8(-9 + 4) = 8(-9) + 8(4) = -72 + 32 = -40`

This produces the same answer as evaluating inside the parentheses first: `8(-5) = -40`.

#### Distribute to Rewrite Algebraic Expressions

Multiply the outside factor by every term inside the parentheses.

- `4(x + 7) = 4x + 28`
- `6(p - 5) = 6p - 30`
- `-2(x - 8) = -2x + 16`
- `5(-3x + 7y) = -15x + 35y`
- `(1/3)(x - 6) = (1/3)x - 2`

**Common trap:** A negative factor changes the sign of every term. For example, `-3(y - 10) = -3y + 30`, not `-3y - 30`.

#### Use Distribution for Mental Math

Break a number into convenient parts.

**Worked example:** Nine helmets cost `$19.95` each.

`9(19.95) = 9(20 - 0.05) = 180 - 0.45 = 179.55`

The total cost is **$179.55**.

This works with decimals and whole numbers because distribution preserves the value of the original product.

#### Distribute More Than One Term

If a whole expression multiplies another sum, distribute each term from the first expression across the second.

`(a + b)(2 + y) = 2a + ay + 2b + by`

> **Challenge:** Distribution works in both directions. Expanding changes a product into a sum or difference; factoring changes a sum or difference back into a product.

### Topic 2: Simplify Algebraic Expressions

#### Parts of an Expression

- A **term** is a number, variable, or product separated from other terms by addition or subtraction.
- A **coefficient** is the numerical factor multiplying a variable. In `x`, the coefficient is `1`; in `-x`, it is `-1`.
- A **constant** is a term without a variable.
- **Like terms** have exactly the same variable parts raised to the same powers. Constants are like terms with other constants.

Examples:

- `3x^2` and `-7x^2` are like terms.
- `8xy^2` and `12xy^2` are like terms.
- `10x^2z` and `22xz^2` are **not** like terms because the exponents do not match.

In `6n - 7n - 4 + n`:

- terms: `6n`, `-7n`, `-4`, `n`
- like variable terms: `6n`, `-7n`, `n`
- coefficients: `6`, `-7`, `1`
- constant: `-4`

#### Simplest Form

An algebraic expression is in **simplest form** when it has no parentheses and no like terms left to combine.

To simplify:

1. Use the Distributive Property to remove parentheses.
2. Rewrite subtraction as addition of the opposite when that clarifies signs.
3. Group like terms.
4. Add or subtract their coefficients.
5. Keep unlike terms separate.

#### Combine Like Terms

Combining like terms uses the Distributive Property in reverse.

**Worked example:** Simplify `4y + y`.

`4y + y = 4y + 1y = (4 + 1)y = 5y`

**Worked example:** Simplify `7x - 2 - 7x + 6`.

`7x - 2 - 7x + 6 = (7 - 7)x + (-2 + 6) = 0x + 4 = 4`

Opposite variable terms cancel because their coefficients add to zero.

**Worked example:** Simplify `5(3x + 4y) - 6(2x + 5y)`.

`15x + 20y - 12x - 30y = 3x - 10y`

#### Expressions in Real Situations

**Markup:** A jacket with original price `j` and a 5% markup costs

`j + 0.05j = 1.05j`.

If `j = 35`, then `1.05(35) = 36.75`, so the new cost is **$36.75**.

**Same number of two items:** If `x` T-shirts cost `$12` each and `x` CDs cost `$7.50` each, the total is

`12x + 7.50x = 19.50x`.

**Perimeter:** Add every side length, then combine like terms. Units for perimeter are linear units such as centimeters, not square units.

#### Check Equivalent Expressions

Substitute the same value for the variable in the original and simplified forms. Matching results provide a useful check, although the algebraic properties are what prove equivalence for every value.

**Common errors:**

- Combining terms that are not like terms: `3x + 4y` cannot become `7xy` or `7x`.
- Forgetting the understood coefficient `1` in `x` or `-1` in `-x`.
- Ignoring a negative sign attached to a term.
- Stopping while parentheses or combinable like terms remain.

### Topic 3: Add Linear Expressions

#### What Is a Linear Expression?

A **linear expression** has variables raised only to the first power. Examples include `x - 7`, `3x + 2`, and `4x + 3y - 5`. Expressions such as `x^2 + 1` or `xy + 2` are not linear in this course because they contain a squared variable or a product of variables.

#### Add by Combining Like Terms

To add linear expressions:

1. Remove parentheses. If a factor is outside, distribute first.
2. Align or group like terms.
3. Add the coefficients of like variable terms.
4. Add the constants.

**Worked example:**

`(2x + 3) + (x + 4) = (2x + x) + (3 + 4) = 3x + 7`

**Worked example with negatives:**

`(2x - 3) + (-x + 4) = (2x - x) + (-3 + 4) = x + 1`

With algebra tiles, positive and negative tiles of the same kind make **zero pairs** and can be removed.

#### Add After Distributing

**Worked example:**

`2(x + 3) + (3x + 1)`

`= 2x + 6 + 3x + 1`

`= 5x + 7`

**Worked example:**

`5(x - 4) + (2x - 7) = 5x - 20 + 2x - 7 = 7x - 27`

#### Perimeter Applications

A triangle has side lengths `(3x - 3)` cm, `(2x + 9)` cm, and `5x` cm.

`P = (3x - 3) + (2x + 9) + 5x = 10x + 6`

If `x = 5`, then `P = 10(5) + 6 = 56` cm.

#### Consecutive Integers

If one integer is `x`, the next consecutive integer is `x + 1`. Their sum is

`x + (x + 1) = 2x + 1`.

Since `2x` is even for every integer `x`, adding 1 makes the sum odd. Therefore, the sum of two consecutive integers is always odd.

**Common errors:**

- Adding unlike terms, such as combining an `x`-term with a constant.
- Forgetting to distribute before combining.
- Losing negative coefficients.
- Evaluating before the expression has been simplified, which creates unnecessary work.

### Topic 4: Subtract Linear Expressions

#### Subtract Like Terms

Subtracting a linear expression means adding its **additive inverse**. The additive inverse of an entire expression is found by multiplying every term by `-1`.

`A - B = A + (-B)`

For example, the additive inverse of `5x - 8` is `-5x + 8`.

#### Subtract with Algebra Tiles

For `(6x + 3) - (2x + 2)`, remove two positive `x`-tiles and two positive unit tiles from the model. The remaining tiles represent `4x + 1`.

If the needed tiles are not present, add **zero pairs** first. A positive and negative tile together have a value of zero, so adding a zero pair does not change the expression.

**Worked example:**

`(-2x - 4) - (2x) = -4x - 4`

Two positive `x`-tiles can be removed after adding two `x` zero pairs.

#### Add the Opposite

**Worked example:**

`(6x + 5) - (3x + 1)`

`= 6x + 5 + (-3x - 1)`

`= 3x + 4`

**Worked example with two negative terms:**

`(-4x - 7) - (-5x - 2)`

`= -4x - 7 + 5x + 2`

`= x - 5`

**Common trap:** The subtraction sign changes every term in the second expression, not only the first one.

#### Comparison Applications

College hats sold are represented by `6m + 3`, and professional hats by `5m - 2`. The number of additional college hats is

`(6m + 3) - (5m - 2) = 6m + 3 - 5m + 2 = m + 5`.

If `m = 10`, then `m + 5 = 15`, so 15 more college hats were sold.

The same structure works for comparing prices, lengths, scores, numbers of customers, or other like quantities.

#### Reverse the Order Carefully

If `A - B = x - 5`, then `B - A = -(x - 5) = -x + 5`. Reversing a subtraction changes the sign of the entire difference.

### Topic 5: Factor Linear Expressions

#### Monomials and Factors

A **monomial** is a number, a variable, or a product of a number and one or more variables. Examples include `25`, `x`, and `40x`. A sum such as `x + 4` is not a monomial.

To **factor** a number or expression means to write it as a product. The **greatest common factor (GCF)** of two or more monomials is the greatest monomial that divides every term.

For variables, include only factors common to every monomial.

- GCF of `4x` and `12x` is `4x`.
- GCF of `18a` and `20ab` is `2a`.
- GCF of `12cd` and `36cd` is `12cd`.

#### Factored Form Is Reverse Distribution

A linear expression is in **factored form** when written as a product of factors.

`8x + 4y = 4(2x + y)`

This reverses the Distributive Property because expanding `4(2x + y)` gives the original expression.

To factor a linear expression:

1. Find the GCF of all terms.
2. Divide each term by the GCF.
3. Write the GCF outside parentheses.
4. Put the quotients inside parentheses.
5. Check by distributing.

#### Factor Using the GCF

**Worked example:** Factor `3x + 9`.

The GCF of `3x` and `9` is `3`.

`3x + 9 = 3(x) + 3(3) = 3(x + 3)`

**Worked example:** Factor `15x + 18`.

The GCF is `3`, so

`15x + 18 = 3(5x + 6)`.

If this expression represents a rectangular area, possible dimensions are `3` units by `(5x + 6)` units.

#### When an Expression Cannot Be Factored Further

In this lesson, an expression such as `12x + 7y` cannot be factored because the two terms have no common factor other than 1.

**Important:** Always factor out the greatest common factor, not merely any common factor. For `40x + 15`, the GCF is `5`, so the complete factored form is `5(8x + 3)`.

#### Check a Factored Expression

Distribute the outside factor. A correct factorization must return the original expression exactly, including every sign.

**Common errors:**

- Taking a variable into the GCF when it is not present in every term.
- Using a common factor that is not the greatest one and stopping too early.
- Dividing only one term by the GCF.
- Losing the negative sign in a difference.
- Confusing area units (square units) with side lengths (linear units).

> **Think Deeper:** Expanding and factoring are inverse processes. This gives a powerful self-check: factor, expand your answer, and compare it term by term with the original expression.

### Unit 2 Strategy Checklist

Before finalizing an answer, ask:

1. Did I identify every term and keep its sign attached?
2. Are the terms truly like terms, with identical variable parts and exponents?
3. Did I distribute to every term inside the parentheses?
4. If the outside factor is negative, did every inside sign change correctly?
5. When adding expressions, did I combine only like terms?
6. When subtracting expressions, did I add the opposite of the entire second expression?
7. When factoring, did I use the GCF of every term?
8. Can I verify a simplified or factored form by substitution or distribution?
9. In a word problem, did I define the variable and include the correct units?
